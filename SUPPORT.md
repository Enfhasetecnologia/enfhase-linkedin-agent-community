# Suporte ao Enfhase LinkedIn Agent

Mantenedor: Enfhase Tecnologia. Assistente de rascunhos para LinkedIn, em português.

Para começar ou resolver dúvidas de instalação, consulte [o guia de instalação](INSTALL.md)
e [os recursos com exemplos](README.md). A experiência depende das capacidades e
permissões do seu aplicativo. Não conecte o LinkedIn nem forneça credenciais.

Para erro comum ou sugestão, abra uma issue neste repositório público. Informe o aplicativo, a versão do pacote, a mensagem de erro e um exemplo
fictício reproduzível. Não inclua conversas privadas, nomes de terceiros, senhas,
tokens, cookies, documentos ou dados confidenciais. O suporte não tem SLA contratado.

Se o assunto envolver vulnerabilidade, use **Security → Advisories → Report a vulnerability**
para relatar a falha de forma privada. O recurso está habilitado. Não publique detalhes
sensíveis em uma issue. Se o formulário não aparecer, não exponha dados sensíveis em uma issue; descreva
somente a dificuldade de acesso ao canal.

O pacote é distribuído sem cobrança. Os planos, custos, disponibilidade e limites
do ChatGPT ou Claude seguem as condições de cada provedor.
